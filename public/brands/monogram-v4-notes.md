# Dark monogram: thicker K outline

`kevin-ks-monogram-dark-v4-outline.svg` preserves the existing KS artwork and native SVG white-K mask. The filter adds a 27-unit black dilation behind the cleaned white silhouette, approximately one CSS pixel at the 42px header size. Only the K is outlined; the gold S and light-mode favicon are unchanged.

The header and dark-mode favicon point to this versioned filename to avoid stale image caches. The previous unoutlined assets remain available as references.
