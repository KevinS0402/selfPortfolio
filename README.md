# Kevin Song Portfolio

Single-page portfolio scaffold for Kevin Song, a Vanderbilt Computer Science major and Business minor in the Class of 2027.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3001` if port `3000` is already occupied.

## Profile Image

The hero portrait loads from `public/profile.jpg`. If that file is missing, the site shows a polished `KS` initials fallback.
